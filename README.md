# 立直麻将 · 风向盘

四人各自打开、同步看分的立直麻将计分网页。规则按 M.League 半庄：随机入座、局中立直、四人填分对账、连庄 / 本场 / 供托、终局 pt，以及个人视角 / 公共视角。

这是微信小游戏的 **Vue 3 + Node.js** 网页版，不依赖微信登录和云开发。同一 Wi-Fi 下用手机浏览器打开即可围桌使用。

## 一键启动

需要本机已安装 [Node.js 18+](https://nodejs.org/)。

```bash
./start.sh
```

或：

```bash
npm install
npm start
```

启动后终端会打印地址：

- 本机：`http://localhost:3000`
- 局域网：`http://192.168.x.x:3000`（牌桌上其他人用这个）

浏览器打开即可。首次会构建前端，之后再启动会直接用已构建的页面。

数据存在本地 `data/store.json`：账号、房间和打完的半庄战绩都会留下，不用装数据库。

## 开发模式

前后端热更新：

```bash
npm install
npm run dev
```

- 前端：`http://localhost:5173`
- 后端：`http://localhost:3000`

## 怎么玩

1. 注册或登录：账号即桌上昵称，再设一个密码。换手机用同一账号密码即可继续，战绩也还在。
2. 一人创建房间，其他人输入四位房号加入；或点房间列表。
3. 满 4 人后随机分配东南西北并开局，各 25000 点。
4. 个人风向盘：自己永远在屏幕下方。
5. 公共视角：大厅输入房号进入，只读，适合放在牌桌中间。
6. 立直立刻 −1000、供托 +1000；可取消本次立直。
7. 任意玩家发起结算：有人和牌 / 流局，以及亲家是否和牌 / 听牌。
8. 四人各自填增减（或无变化），只校验点数守恒和供托。
9. 半庄结束给出素点、名次和 M.League pt。
10. 任意玩家可连续撤销上一局结算。

等待房里有「补齐测试玩家」，方便一个人把流程走通。

## 部署到阿里云 ECS

生产访问路径与花火牌一致，挂在域名二级目录：

- https://dodomogu.com/mahjong-wind/
- 前端 base / API / Socket 见 `client/.env.production`

本机执行（需能 SSH 登录那台机器）：

```bash
./deploy.sh root@你的公网IP
```

默认装到 `/opt/mahjong-wind`，Node 监听 **3010**，由 nginx 把 `/mahjong-wind/` 反代过去。再次执行会更新代码，**不会覆盖** 服务器上已有的 `data/store.json`。
